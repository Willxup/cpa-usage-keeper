# Domain documentation

This is a single-context repository.

Before exploring a domain, read:

- `GLOSSARY.md` at the repository root, when present.
- Applicable decisions under `docs/adr/`, when present.

If these files do not exist, proceed without creating them until domain terminology or an architectural decision requires them. Use established repository terms in issue titles, specs, tests, and code. Surface conflicts with existing ADRs instead of silently overriding them.
