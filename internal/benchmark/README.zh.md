# Benchmark

[English](README.md)

查看报告了解实测结果，按运行指南复现。所有测试使用合成数据。

| 测试 | 测量内容 | 最新报告 | 运行方法 |
| --- | --- | --- | --- |
| 容量 | 1、2、4 核下的持续接收能力和 Dashboard 延迟 | [容量报告](reports/capacity/README.zh.md) | [容量运行指南](guides/capacity.zh.md) |
| 价格 | 百万／千万事件的首次迁移、历史重算和查询耗时 | [价格报告](reports/pricing/README.zh.md) | [价格运行指南](guides/pricing.zh.md) |

容量报告执行于费用持久化重构之前，不代表当前实现的容量。价格报告在固定输入速率下测迁移和重算，不替代容量测试。

## 更新报告

每次测试使用仓库外的新目录，数据库、WAL、二进制和原始日志留在当地。完整运行并核验后，整体替换对应主题的报告及结果文件；新测试完成前保留旧报告，历史由 Git 保存。`reports/` 不建立日期、版本或轮次目录。

报告统一包含结论、环境与限制、数据集、测试代码或二进制标识、结果、复现步骤；中英文同步。如实报告最终测量结果与限制；排障过程及被替代的中间实验留在本地记录，未执行项目不能当作成功的零值。

仅发布审核后的 Markdown、结构化测量结果及源码校验值。移除主机名、SSH 别名、私有地址、用户名和本机绝对路径，保留硬件、软件版本、负载参数及真实测量值。源码清单记录当时的测试代码，不因后续文档或仅脱敏的改动而改写。
